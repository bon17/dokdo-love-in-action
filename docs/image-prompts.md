# 「독도 타임 패트롤」 이미지 프롬프트

게임에 들어갈 그림을 AI 이미지 생성 도구(ChatGPT, Gemini 등)로 만들 때 쓰는 프롬프트 모음입니다.
프롬프트 블록을 **통째로 복사해서** 붙여넣으면 됩니다. 한국어 그대로 써도 됩니다.

---

## 먼저 읽어 주세요

### 만드는 순서

1. **C1 가지(기본)** 를 가장 먼저 만듭니다. 이 그림이 캐릭터의 기준이 됩니다.
2. 나머지 가지 그림(C2~C4)과 엔딩(E1)은 **C1 그림을 첨부한 뒤** 프롬프트를 넣습니다.
   프롬프트 첫 줄의 "첨부한 캐릭터와 똑같은 모습으로"가 그 뜻입니다.
3. 배경은 순서 상관없이 만들어도 됩니다.
4. ChatGPT라면 **한 대화창에서 이어서** 만들면 그림체가 비슷하게 유지됩니다.

### 공통 규칙 (프롬프트에 이미 들어 있어요)

- **그림 안에 글자를 넣지 않습니다.** AI는 한글을 깨뜨려 그리기 때문에, 제목·대사·설명은 모두 게임 코드에서 따로 올립니다.
- **국기는 그리지 않습니다.** AI가 태극기 괘를 틀리게 그리는 경우가 많습니다.
- 배경은 **가로형(16:9)**, 캐릭터·물건은 **정사각형(1:1) + 투명 배경**입니다.
  투명 배경이 안 되는 도구라면 무늬 없는 단색 배경으로 받아 주세요. 배경은 제가 지워 보겠습니다.
- 배경 그림은 **아래쪽 3분의 1을 단순하게** 비워 둡니다. 게임에서 대사창이 올라가는 자리입니다.

### 다 만든 뒤 확인할 것

- [ ] 글자처럼 보이는 낙서나 깨진 글자가 없나요?
- [ ] 국기가 들어가 있지 않나요?
- [ ] 독도 모양이 맞나요? **서도(왼쪽)가 더 높고 뾰족하고, 동도(오른쪽)는 낮고 꼭대기가 평평**해야 합니다.
- [ ] 가지가 그림마다 같은 모습인가요? (회갈색 몸, 베이지색 주둥이, **주황색 스카프**)
- [ ] 사람 얼굴이나 손가락이 이상하지 않나요?
- [ ] 특정 나라 사람을 우스꽝스럽거나 나쁘게 그리지 않았나요?

이상하면 같은 프롬프트로 다시 만들거나 "글자를 모두 지워 줘"처럼 고쳐 달라고 하면 됩니다.

### 이미지 없이 코드로 만드는 것

아래는 정확성이 중요해서 AI 그림을 쓰지 않고 게임 코드로 직접 그립니다. 따로 만들지 않으셔도 됩니다.

| 코드로 만드는 것 | 이유 |
|---|---|
| 동해 지도 (한반도·울릉도·독도·오키섬) | AI 지도는 위치와 거리가 틀리기 쉽습니다. 87.4km, 동남쪽 같은 사실이 정확해야 합니다. |
| 옛 문서와 사료 내용 | AI로 사료 그림을 만들면 가짜 사료가 됩니다. 학생이 진짜로 오해할 수 있고 글자도 깨집니다. |
| 증거 카드, 버튼, 점수판, 연표 카드 | 글자가 들어가는 화면 요소입니다. |
| 정보 부표, 거짓 주장 풍선, 도장 효과 등 작은 물체 | 움직임과 크기를 코드로 조절해야 합니다. |
