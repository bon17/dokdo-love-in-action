# 「독도 타임 패트롤: 사라진 기록을 찾아라」 기획서

기산중학교 독도 사랑 실천대회 1교시에 학생들이 플레이하는 학습 게임의 기획서입니다.
게임을 만들고 고칠 때 이 문서를 기준으로 삼습니다.

| 항목 | 내용 |
|---|---|
| 대상 | 중학교 1~3학년 |
| 쓰는 곳 | 기산중학교 독도 사랑 실천대회 1교시 (2교시는 퀴즈 대회) |
| 목표 | 독도에 대한 이해, 독도가 우리 땅인 근거, 갈등이 생긴 까닭을 스스로 알아가게 하기 |
| 형식 | HTML 파일 하나, 인터넷 없이도 실행 |
| 배포 | GitHub Pages에 올리고 QR 코드로 나눠 줌 |
| 기기 | 안드로이드 태블릿, 크롬 브라우저, 가로 화면, 터치 조작 |
| 플레이 시간 | 약 40분 |

## 1. 가장 중요한 원칙: 정답이 아니라 지식 습득

이 게임은 **답을 알려 주는 게임이 아니라, 공부할 거리를 주는 게임**입니다.
게임이 퀴즈의 정답을 직접 알려 주면 대회의 의미가 사라집니다.
게임을 대충 넘긴 학생보다 **이야기를 꼼꼼히 읽고 증거 도감으로 한 번 더 공부한 학생이 대회에서 상을 받도록** 만듭니다.

| 하는 것 (지식 습득) | 하지 않는 것 (정답 알려 주기) |
|---|---|
| 사건의 배경, 흐름, 의미, 원인과 결과를 이야기와 사료 속에 담기 | 퀴즈와 같은 질문이나 보기 내기 |
| 인물, 연도, 사료 이름은 이야기 속에 자연스럽게 등장 | 정답만 뽑아 굵게 강조하거나 "꼭 외우기" 표시하기 |
| 미션은 **"왜? 어떻게? 무엇이 이상해?"** 같은 이해와 추론을 물음 | 미션에서 **"누구? 몇 년? 이름은?"** 같은 암기 사실을 물음 |
| 증거 도감은 사건의 맥락과 의미를 담은 기록 | 문항별 정답 요약표나 "퀴즈 대비" 안내 |

### 발견형 설계 원칙

1. **먼저 겪고, 나중에 알게 하기.** 설명을 먼저 보여 주지 않습니다. 문서를 읽고, 물건을 살펴보고, 배를 몰면서 학생이 먼저 발견합니다.
2. **사실이 곧 게임의 도구.** 그 내용을 이해해야 자물쇠가 열리고, 배가 도착하고, 논쟁에서 이깁니다.
3. **가지는 설명하지 않고 궁금해하기.** "정답은 ○○야" 대신 "여기 뭐라고 적혀 있어? 이상하지 않아?"처럼 묻습니다.
4. **틀리면 정답 대신 단서로 돌려보내기.** "서고의 세 번째 책장을 다시 볼까?"처럼 단서가 있는 곳을 가리킵니다. 3번 틀리면 가지와 함께 이야기 속에서 발견하고 넘어갑니다. 딱딱한 정답 알림은 쓰지 않습니다.
5. **퀴즈와 비슷한 모양 피하기.** 게임 안에는 퀴즈 같은 문장, 보기, 문항 번호가 나오지 않습니다.
6. **정리는 학생이 하기.** 증거 카드는 "내가 찾은 증거" 기록입니다. 결과 화면의 3줄 설명도 학생이 먼저 완성한 뒤에 예시를 보여 줍니다.

### 저장소에 넣지 않는 것

이 저장소는 공개되어 있습니다. 아래 자료는 저장소와 게임 어디에도 넣지 않습니다.

- 퀴즈 문항 원문과 정답
- 퀴즈 문항과 게임 단계의 대응표 (선생님만 보관)
- 「독도는 우리 땅」 가사 원문과 음원
- 외교부 「독도 역사 연표」 지도 이미지 (저작권 표시가 있음)

## 2. 줄거리

- **발단:** 기산중학교 독도 사랑 실천대회가 열리는 날 아침, 학교 도서관의 독도 기록이 하나씩 백지로 변하기 시작합니다. 기록을 지우는 것은 정체를 알 수 없는 **'망각의 안개'**입니다.
- **주인공:** 학생은 독도 타임 패트롤의 신입 대원이 됩니다. 멸종한 독도 강치의 기억을 간직한 **'가지'**와 함께 시간여행 배 **'우산호'**를 타고 각 시대로 가서 사라진 증거를 되찾습니다.
- **진행 표시:** 증거를 찾을 때마다 화면 속 흐려진 독도가 조금씩 선명해집니다.
- **절정:** 안개의 정체는 '근거 없는 주장'이었습니다. 국제 토론장에서 모은 증거로 반박합니다.
- **결말:** 안개가 걷히고 독도에 해가 떠오릅니다.
- **악역은 가상의 존재입니다.** 특정 나라 사람을 비난하지 않고, 근거로 차분하게 말하는 태도를 배웁니다.

## 4. 게임 전체 장치

- **증거 카드 (약 33장):** 단계마다 모으는 "내가 찾은 증거" 기록입니다.
  - 일반·희귀·전설 등급이 있고, 얻을 때 도장 찍는 연출이 나옵니다.
  - 카드마다 **역사적 근거 / 지리적 근거 / 국제법적 근거** 중 어디에 속하는지 표시합니다.
- **증거 보드:** 단계가 끝날 때 새로 모은 카드를 세 가지 근거로 분류합니다. 30초 안팎으로 짧게 합니다.
- **증거 도감:** 모은 카드를 언제든 다시 볼 수 있는 곳입니다. 사건의 맥락과 의미를 담고, 정답 요약표처럼 만들지 않습니다.
- **노래 단서 수첩:** 1단계 라디오에서 모은 노래 속 단서 9개가 뒤 단계에서 해당 증거를 찾을 때 하나씩 풀립니다. (7장 참고)
- **숨은 강치:** 단계마다 한 마리씩 숨어 있는 강치를 찾는 숨은 요소입니다.
- **업적 배지:** 무실수, 스피드 항해사 등입니다.
- **점수와 등급:** 점수, 콤보, 단계별 별 3개, 최종 등급(S~C), 클리어 시간입니다.
- **게임 오버 없음:** 틀려도 게임이 끝나지 않습니다. 힌트를 거쳐 넘어가고 점수만 줄어듭니다.

## 5. 결과 화면 (임명장 대신)

- 맨 위에 **기산중학교 독도 사랑 실천대회**를 표시합니다.
- 대원 이름, 점수, 등급(S~C), 클리어 시간을 보여 줍니다.
- 모은 증거 수, 노래 단서 확인 수, 찾은 숨은 강치 수, 업적 배지도 보여 줍니다.
- **'독도가 우리 땅인 이유' 3줄 설명:** 학생이 모은 카드로 역사적·지리적·국제법적 근거를 한 줄씩 먼저 완성하고, 그다음에 예시 문장을 보여 줍니다.
- 실천 다짐이나 에필로그는 넣지 않습니다.

## 6. 시간 관리 (목표 약 40분)

| 구간 | 목표 시간 |
|---|---|
| 오프닝 | 2분 |
| 1단계 + 우산호 라디오 | 5분 |
| 2~7단계 | 단계당 4~5분, 합계 27분 |
| 8단계 | 5분 |
| 결과 화면 | 1~2분 |
| **합계** | **약 40분** |

- **짧게:** 한 단계의 미니게임은 2개까지, 대사는 한 장면에 3~4줄입니다. 화면을 누르면 대사가 바로 끝까지 나옵니다. 퍼즐 하나는 1~2분 안에 풀리게 합니다.
- **단서는 숨기지 않기:** 발견형이라도 단서는 눈에 잘 띄게 둡니다.
- **힌트 단계:** 2번 틀리면 힌트가 나오고, 3번 틀리면 이야기 속에서 함께 발견하고 넘어갑니다.
- **늦은 학생:** 35분쯤 선생님이 비밀번호 **1025**(독도의 날)를 알려 주면 바로 8단계로 갈 수 있습니다.
- **빨리 끝낸 학생:** 증거 도감 복습, 숨은 강치 찾기, 재도전해서 S등급에 도전하기.

## 7. 「독도는 우리 땅」

### 재생 방식

- 수업을 시작할 때 **선생님이 교실 스피커로 한 번** 틀어 줍니다.
- 게임 속 **'우산호 라디오'** 장면(1단계 출항)에는 짧은 소개, '다시 듣기' 버튼, '노래 속 독도 찾기' 미니게임을 넣습니다.
- '다시 듣기' 버튼 링크: <https://youtu.be/mxC4wbLGvJs>
- 음원은 게임 파일에 넣지 않습니다.

### 가사 사용 원칙

- 가사를 통째로 넣지 않고, 가사에 나오는 **짧은 사실 단어만** 단서로 씁니다.
- 노래 단서 9개와 풀리는 단계는 다음과 같습니다.

| 단서 주제 | 풀리는 단계 |
|---|---|
| 울릉도에서의 방향과 거리 | 1 |
| 새들의 고향 | 1 |
| 주소 (행정구역이 바뀌어 가사가 고쳐진 이야기 포함) | 1 |
| 섬의 넓이 | 1 |
| 바다 생물 (어장) | 7 |
| 주민과 이장 | 7 |
| 지증왕 때의 우산국, 신라 장군 | 2 |
| 조선의 지리 기록 | 2 |
| 러일전쟁과 '임자 없는 땅' 주장 | 5 |

- **팩트 체크 장면:** 가사에는 "러일전쟁 **직후**"라고 나오지만, 실제 편입 시도는 러일전쟁이 **한창일 때**였습니다. 5단계에서 학생이 날짜 단서로 스스로 바로잡게 합니다.
- **넣지 않는 부분:**
  - 대마도 관련 구절. 대한민국 정부는 대마도 영유권을 주장하지 않으므로 독도 근거와 섞이지 않게 뺍니다. 노래를 틀 때 선생님이 한마디 설명하면 좋습니다.
  - 평균기온, 강수량, 숫자 구절. 퀴즈와 관계없고 확인이 어려워 뺍니다.

## 9. 디자인과 기술

- **이미지:** 선생님이 만든 22장과 도서관 그림(필수 1장, 선택 1장)을 씁니다. 목록과 파일 이름은 [image-prompts.md](image-prompts.md)에 있습니다.
  - 원본은 합쳐서 약 40MB입니다. 태블릿에서 빨리 열리도록 압축해서 전체 3~4MB 정도로 게임 파일에 넣습니다.
  - 그림에는 글자가 없습니다. 모든 한국어 글자는 코드로 올립니다.
- **코드로 그리는 것:** 동해 지도, 옛 문서와 사료 내용, 연표, 증거 카드, 버튼과 점수판, 작은 게임 물체(정보 부표, 풍선, 도장 효과).
- **BGM:** 음원 파일 없이 코드로 작곡합니다.
  - 분위기별 5곡: 항해(경쾌), 서고와 추리(미스터리), 연표 러시(긴박), 보스전(비장), 엔딩(웅장)
  - 효과음: 파도와 갈매기, 정답과 오답, 카드 획득, 도장 찍기
  - 기본 볼륨은 낮게, 음소거 버튼을 둡니다. 이어폰 사용을 권합니다.
- **태블릿:** 가로 화면 기준, 큰 터치 버튼, 전체 화면 버튼을 둡니다.
- **저장:** 진행 상황이 자동 저장되어 새로고침해도 이어서 할 수 있습니다. 공용 기기를 위해 '새로 시작' 버튼을 둡니다.
- **교사 모드:** 시연용으로 모든 단계를 열 수 있습니다.

## 10. 내용 정확성

- 사료 그림은 AI로 만들지 않습니다. 가짜 사료가 되어 학생이 진짜로 오해할 수 있습니다.
- 지도는 위치와 거리가 정확하도록 코드로 그립니다.
- 도해면허 연도는 외교부 연표 지도에 맞춰 1625년으로 씁니다.
- SCAPIN 제677호는 최종 영토 결정이 아니라는 단서가 있다는 점을 함께 적습니다.
- 우리 정부의 입장을 설명할 때 '영유권 분쟁은 존재하지 않는다'는 표현의 뜻을 정확히 전합니다.
- 일본 사람이나 일본이라는 나라를 비하하는 표현은 쓰지 않습니다.
- 확인할 수 없는 수치는 넣지 않습니다.
