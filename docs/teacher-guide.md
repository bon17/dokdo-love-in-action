## 1. GitHub Pages 켜기

게임을 인터넷 주소로 열 수 있게 합니다.

1. 저장소 [bon17/dokdo-love-in-action](https://github.com/bon17/dokdo-love-in-action)에서 위쪽 **Settings**를 누릅니다.
2. 왼쪽 메뉴에서 **Pages**를 누릅니다.
3. **Build and deployment**에서 다음과 같이 고릅니다.
   - Source: **Deploy from a branch**
   - Branch: **claude/peaceful-einstein-rafma5**, 폴더는 **/ (root)**
4. **Save**를 누르고 1~3분 기다립니다.
5. 아래 주소가 열리면 성공입니다.
   - 게임: <https://bon17.github.io/dokdo-love-in-action/>
   - 선생님용 랭킹 보드: <https://bon17.github.io/dokdo-love-in-action/ranking.html>

게임 주소 QR 코드는 [qr-game.png](qr-game.png)에 있습니다. 인쇄하거나 TV에 띄우세요.
랭킹 보드 화면 오른쪽에도 같은 QR 코드가 나옵니다.

> 나중에 이 브랜치를 main에 합치면, Pages의 Branch도 **main**으로 바꿔 주세요.

## 2. 랭킹용 구글 시트와 웹 앱 만들기

학생 점수는 선생님의 구글 시트에만 저장됩니다. 게임 화면에는 이름 가운데 글자를 가려서 보여 줍니다.

> **개인 구글 계정을 권합니다.** 학교 계정(구글 워크스페이스)은 관리자 설정 때문에
> 로그인하지 않은 태블릿에서 접속이 막힐 수 있습니다.

### 2-1. 시트와 스크립트 만들기

1. 개인 구글 계정으로 로그인하고 <https://sheets.new> 를 엽니다. 시트 이름을 "독도 타임 패트롤 랭킹"으로 바꿉니다.
2. 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다.
3. 편집기에 있는 코드를 모두 지우고, 이 저장소의 [gas/Code.gs](../gas/Code.gs) 내용을 통째로 복사해 붙여 넣습니다.
4. 💾 **저장**을 누릅니다.

### 2-2. 처음 한 번 실행해서 권한 허용하기

1. 위쪽의 함수 선택 칸에서 **setup**을 고르고 **▶ 실행**을 누릅니다.
2. "권한 검토 필요" 창이 뜨면 **권한 검토 → 내 계정 선택**을 누릅니다.
3. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용**을 누릅니다.
   선생님이 직접 만든 스크립트라서 나오는 안내이니 괜찮습니다.
4. 시트에 **랭킹**, **기록** 두 탭이 생기면 성공입니다.

### 2-3. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. ⚙️(유형 선택)에서 **웹 앱**을 고릅니다.
3. 다음과 같이 설정합니다.
   - 설명: 독도 랭킹
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 둡니다.
5. 확인: 복사한 주소 끝에 `?action=list`를 붙여 브라우저에서 열어 보세요. `{"ok":true,"rows":[]...}` 가 보이면 성공입니다.

> 나중에 스크립트 코드를 고쳤다면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 누르세요.
> 이렇게 하면 웹 앱 주소가 바뀌지 않습니다. ("새 배포"를 누르면 주소가 바뀝니다.)

## 3. 게임에 랭킹 주소 넣기

1. 저장소에서 [config.js](../config.js) 파일을 엽니다.
2. 오른쪽 위 ✏️(Edit this file)를 누릅니다.
3. `rankingUrl: ""` 의 따옴표 안에 2-3에서 복사한 웹 앱 주소를 붙여 넣습니다.

   ```js
   rankingUrl: "https://script.google.com/macros/s/……/exec",
   ```

4. **Commit changes…** 를 누르고, 다시 한번 **Commit changes**를 누릅니다.
5. 1~2분 뒤 랭킹 보드(ranking.html)를 새로 고쳐 "아직 기록이 없어요"가 보이면 연결된 것입니다.

같은 파일의 `teacherCode`는 교사 모드 비밀번호입니다. 원하는 숫자로 바꿔도 됩니다.
이 저장소는 공개되어 있어서 누구나 이 파일을 볼 수 있지만, 교사 모드로 한 기록은 랭킹에 저장되지 않으니 대회에는 영향이 없습니다.

## 4. 태블릿으로 미리 해 보기

수업 전에 학생용 안드로이드 태블릿 한 대로 확인하세요.

- [ ] 크롬으로 QR 코드를 찍어 게임이 열린다.
- [ ] 소리가 난다. (처음 화면을 한 번 누른 뒤부터 소리가 납니다.)
- [ ] 오른쪽 위 ⛶ 버튼으로 전체 화면이 된다.
- [ ] 1단계 라디오의 "노래 다시 듣기"를 누르면 유튜브가 새 창으로 열린다.
- [ ] 교사 모드에서 단계를 옮겨 다니며 화면이 잘 나온다.
- [ ] 한 판을 끝까지 해서 점수가 랭킹 보드에 올라온다. (4분보다 짧게 끝낸 기록은 저장되지 않습니다.)
- [ ] 미리 해 본 기록은 시트에서 지운다. (아래 "기록 지우기" 참고)

> 안드로이드의 파일 앱에서 HTML 파일을 직접 열면 게임이 제대로 돌아가지 않을 수 있습니다. 꼭 크롬에서 주소로 여세요.

| 45–55분 | 증거 도감으로 복습 |

학생들은 이어폰 없이 하므로 태블릿 소리를 아주 작게 하거나 끄게 합니다. 소리가 없어도 게임은 모두 할 수 있습니다.

### 학생에게 알려 줄 것

- **밑줄 친 낱말:** 대사, 옛 문서, 증거 카드에서 주황색 밑줄이 그어진 낱말을 누르면 뜻이 나옵니다. 대사 창의 낱말을 눌러도 대사는 넘어가지 않습니다. 모아 보기는 📖 도감 → **낱말 풀이** 탭.
- **대사 넘기기:** 글자가 다 나오고 ▼ 표시가 뜬 뒤에 눌러야 다음 대사로 넘어갑니다. 스페이스바와 엔터로는 넘어가지 않습니다.
- **숨은 강치:** 1~8단계 화면 가장자리마다 강치가 한 마리씩 숨어 있습니다. 누르면 +50점, 8마리를 모두 찾으면 "강치 친구" 배지를 받습니다. 단계 시작 미션 카드에 몇 마리 찾았는지 나옵니다.
- **다시 읽기:** 서고의 역사책·연대표·흐려진 책, 막부 관청의 책과 편지, 신문사 취재 자료, 7단계 독도의 모습들은 한 번 본 뒤에도 다시 눌러 읽을 수 있습니다. (점수는 처음 한 번만)
- **⏱ 지난 시간:** 위쪽 막대에 지금까지 플레이한 시간이 나옵니다. 랭킹의 클리어 시간과 같고, 화면이 꺼져 있던 동안은 세지 않습니다.

### 태블릿을 여러 학생이 번갈아 쓸 때

- 시작 화면에서 **새로 시작**을 누르면 앞 학생의 진행 상황이 지워지고 새로 등록합니다.
- 게임 중에는 ☰ 메뉴 → **처음 화면으로 (새로 시작)** 을 누르세요.
- 진행 상황은 자동으로 저장되어, 실수로 창을 닫아도 **이어하기**로 계속할 수 있습니다.

### 점수와 등급

- 미니게임을 한 번에 풀수록, 증거 분류를 정확히 할수록, 연속으로 맞힐수록(콤보) 점수가 높습니다.
- 틀려도 게임이 끝나지 않습니다. 힌트를 거쳐 넘어가고 점수만 조금 줄어듭니다.
- 등급: S 7,344점 이상, A 6,048점 이상, B 4,320점 이상, 그 아래는 C.
- 랭킹 순서: 점수가 높은 순, 같으면 클리어 시간이 짧은 순. 다시 도전하면 최고 기록만 반영됩니다.

## 게임을 고치고 싶을 때

게임 파일 `index.html`은 `src/` 폴더의 코드와 `images/` 폴더의 그림을 합쳐서 만든 파일입니다.
`index.html`을 직접 고치지 말고 아래처럼 하세요.

1. `src/js/` 에서 해당 단계 파일을 고칩니다. (예: 3단계는 `12-stage3.js`, 증거 카드 내용은 `00-data.js`)
2. `pip install pillow qrcode` 후 `python3 tools/build.py` 를 실행하면 `index.html`, `ranking.html`, `guide.html`이 새로 만들어집니다.
3. 바뀐 파일을 커밋합니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 학생용 게임 (만들어진 파일) |
| `ranking.html` | 선생님용 랭킹 보드 (만들어진 파일) |
| `guide.html` | 임장 선생님 가이드 (만들어진 파일) |
| `config.js` | 랭킹 주소, 교사 모드 비밀번호 |
| `gas/Code.gs` | 구글 앱스 스크립트 랭킹 서버 코드 |
| `src/` | 게임 코드와 화면 틀 (임장 가이드 본문은 `src/guide.template.html`) |
| `images/` | 선생님이 만든 그림 원본 (임장 가이드의 게임 화면 사진은 `images/guide/`) |
| `tools/build.py` | `index.html`, `ranking.html`, `guide.html`을 만드는 도구 |
| `docs/game-plan.md` | 기획서 |
| `docs/image-prompts.md` | 그림 만들기 프롬프트 |
