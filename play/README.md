# 독도 타임 패트롤 (다른 학교용)

기산중학교 독도 사랑 실천대회용 게임에서 학교 이름, 4교시 퀴즈 안내, 실시간 랭킹을 뺀 버전입니다. 어느 학교에서나 크롬북으로 플레이할 수 있습니다.

- 게임: <https://bon17.github.io/dokdo-love-in-action/play/>
- 선생님 가이드: <https://bon17.github.io/dokdo-love-in-action/play/guide.html>
- 게임 주소 QR 코드: [qr-game.png](qr-game.png)

기산중 버전(<https://bon17.github.io/dokdo-love-in-action/>)은 그대로 남아 있습니다. 바꾸기 전 모습은 git 태그 `gisan-final`에도 남겨 두었습니다.

## 기산중 버전과 다른 점

| | 기산중 버전 | 다른 학교용 버전 |
|---|---|---|
| 학교·대회 이름 | 시작 화면, 오프닝, 결과 화면에 나옴 | 뺌 ("학교 도서관"으로만 나옴) |
| 4교시 퀴즈 안내 | 시작 안내, 결과 화면에 나옴 | 뺌 |
| 대원 등록 | 학년, 반, 이름 | 이름만 (2~12자, 한글·영문·숫자) |
| 실시간 랭킹 | 결과 화면, 랭킹 보드, 구글 시트 | 뺌 (점수를 어디에도 보내지 않음) |
| 결과 화면 | 점수, 등급, 랭킹 | 점수, 등급, **등급 기준**, **내 칭호(업적 배지)** |
| 교사 모드 비밀번호 | 3810 | **neis** (대문자, 한글 자판 그대로 써도 됨) |
| 진행 기록 저장 이름 | `dokdoTP.*` | `dokdoTPplay.*` (같은 크롬북에서 두 버전 기록이 섞이지 않음) |

점수, 등급(S·A·B·C), 업적 배지, 내 최고 기록(크롬북에 저장), 8단계 게임 내용, 늦은 학생용 비밀번호 1025는 그대로입니다.

## 비밀번호

| 비밀번호 | 넣는 곳 | 하는 일 |
|---|---|---|
| **1025** | 게임 중 ☰ → 🔑 비밀번호 입력 | 8단계로 바로 가기 (건너뛴 단계 증거는 점수 절반) |
| **neis** ([config.js](config.js)의 `teacherCode`) | 시작 화면 오른쪽 아래 "선생님" | 교사 모드: 단계 고르기, 모든 증거 받기, 이 기기 기록 지우기 |

교사 모드 비밀번호를 바꾸려면 GitHub에서 `play/config.js`를 열어 연필(✏️) 버튼으로 고친 뒤 "Commit changes"를 누르세요. 다시 만들 필요 없이 바로 반영됩니다.

## 만들기

`play/index.html`, `play/guide.html`, `play/qr-game.png`는 아래로 만든 파일입니다. 직접 고치지 말고 `play/src/`를 고친 뒤 다시 만드세요.

```sh
pip install pillow qrcode fonttools brotli
python3 tools/build_play.py
```

| 파일 | 내용 |
|---|---|
| `play/src/` | 게임 코드와 가이드 원본 (기산중 버전 `src/`를 복사해 고친 것) |
| `play/images/guide/` | 이 버전에서 다시 찍은 가이드 화면 사진 (없는 사진은 `images/guide/` 것을 씀) |
| `play/config.js` | 교사 모드 비밀번호 |
| `tools/build_play.py` | 이 버전을 만드는 스크립트 (기산중 버전 파일은 건드리지 않음) |

게임 그림은 저장소의 `images/`를 함께 씁니다.
