# 글꼴 넣는 곳

이 폴더에 **리디바탕(RIDIBatang)** 글꼴 파일을 하나 올려 주세요.

- 파일 형식: `.otf`, `.ttf`, `.woff`, `.woff2` 중 아무거나 괜찮아요. (예: `RIDIBatang.otf`)
- 올린 뒤 게임을 다시 만들면(`python3 tools/build.py`) 게임에 쓰는 글자와 자주 쓰는 한글 2,350자만 남겨
  작게 줄인 글꼴이 `index.html`과 `ranking.html` 안에 들어가요. 인터넷이 느려도 글꼴이 바로 보여요.
- 이 폴더가 비어 있으면 게임은 인터넷(눈누 CDN)에서 리디바탕을 불러와요.
